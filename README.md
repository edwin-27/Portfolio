# Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website developed using HTML5, CSS3, and Bootstrap 5. The website showcases my background, technical skills, software projects, gallery, and contact information.

The website contains the following pages:

- Home
- About
- Skills
- Projects
- Gallery
- Contact

The project demonstrates responsive web design principles, semantic HTML structure, Bootstrap components, and modern CSS styling.

---

- HTML5
- CSS3

- GitHub
