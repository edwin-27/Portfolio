Personal Portfolio Website
Project Overview

This project is a responsive personal portfolio website developed using HTML5, CSS3, and Bootstrap 5. The website showcases my background, technical skills, software projects, gallery, and contact information. It demonstrates the use of semantic HTML, responsive web design principles, Bootstrap components, and CSS styling.

The website contains six pages:

Home
About
Skills
Projects
Gallery
Contact

The navigation bar is available on every page, allowing users to easily move throughout the website.
